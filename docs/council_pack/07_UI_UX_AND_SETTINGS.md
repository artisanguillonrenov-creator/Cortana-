# 7. UI/UX Android et réglages

## 7.1 Navigation
Réglages > Intelligence > Conseil de réflexion

## 7.2 Écran principal
- toggle Conseil de réflexion;
- mode : Auto / Rapide / Renforcé / Conseil 4 / Approfondi / Personnalisé;
- afficher résumé du conseil;
- profil budget : Éco / Équilibré / Qualité / Personnalisé.

## 7.3 Modèles
Option :
- Même modèle pour tous.
- Personnaliser par rôle.

Pour chaque rôle :
- provider;
- modèle;
- fallback;
- effort;
- local/cloud;
- tokens;
- timeout.

## 7.4 Débat
- tours max;
- topologie;
- protocole décision;
- challenge final;
- juge;
- quorum;
- early stop.

## 7.5 Coûts
- max tokens/run;
- max coût/run;
- max quotidien;
- avertissement;
- petit modèle autorisé pour filtre/judge.

## 7.6 Pendant exécution
Afficher :
- « 4 analyses en cours »;
- états des slots;
- analyse / confrontation / vérification / synthèse;
- bouton STOP.

Ne pas afficher chain-of-thought.

## 7.7 Carte finale
« Résumé du conseil »
- consensus;
- points d’accord;
- risques restant;
- preuves;
- nombre d’agents;
- durée;
- option détails techniques.

## 7.8 Mode développeur
Peut afficher :
- modèles;
- providers;
- tokens;
- latence;
- distribution votes;
- nombre d’arguments retenus;
- erreurs/fallbacks.

## 7.9 Messages erreur
Exemples :
- « 1 spécialiste indisponible, réponse produite avec 3/4. »
- « Budget atteint : arrêt après le premier tour. »
- « Modèle incompatible : fallback appliqué. »
- « Contexte trop volumineux : compactage appliqué. »

## 7.10 Accessibilité
- TalkBack;
- labels;
- contraste;
- cibles tactiles Android;
- pas d’information uniquement par couleur;
- rotation/tablette.
